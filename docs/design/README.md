## How a section is written

Each section ends in decisions, not a survey. For every decision:

1. **Decision** — one or two sentences.
2. **Alternatives considered** — and why not.
3. **Guidance item** — the row in [`../anthropic-conformance.md`](../anthropic-conformance.md) it satisfies.
4. **Open question for the behavior scientists** — what we could not settle without them.

Aim for two pages a section. Cite primary sources with links. If a claim came from a model,
check it against the source before it goes in. The "questions to settle" in each stub are a
starting list from a first read of the brief; owners should cut, add and reorder freely.

Owners write; reviewers try to break it. Everyone reads every section before Oct 10.
